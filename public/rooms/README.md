# Room backdrops

Drop a CC0 / royalty-free room illustration here to use it as the pet room
background. If a theme has no image, the app falls back to the built-in CSS room.

## How to add
Save an image named exactly after the room theme id:

| Theme id | File |
|----------|------|
| cozy   | `public/rooms/cozy.jpg` |
| meadow | `public/rooms/meadow.jpg` |
| beach  | `public/rooms/beach.jpg` |
| night  | `public/rooms/night.jpg` |
| snow   | `public/rooms/snow.jpg` |
| cave   | `public/rooms/cave.jpg` |
| candy  | `public/rooms/candy.jpg` |
| space  | `public/rooms/space.jpg` |

Then hard-refresh — that theme uses the image automatically (furniture & buddy
render on top). `.jpg` is expected; keep each image small (~100–300 KB).

## Where to get free CC0 room art (no attribution required)
- **Kenney.nl** — search "interior" / "isometric" packs (CC0). Download the zip,
  then export/screenshot a room scene, or use a pre-made background.
- **OpenGameArt.org** — filter by CC0, search "room" / "interior background".
- **itch.io** — many free "cozy room" / "bedroom" background packs.
- **Pixabay** (illustrations, CC0-like) — search "cute room illustration".

Tip: pick a slightly top-down / flat illustration so furniture sitting on the
floor lines up nicely. Landscape orientation works best (the stage is wide).
